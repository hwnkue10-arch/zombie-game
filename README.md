## 🌟 프로젝트 소개

**BOXHEAD: THE CORE v3.1**은 클래식 플래시 명작 '박스헤드'의 감성을 계승하고, **Three.js 3D 렌더링, Web Audio API 사운드 합성, 절차적 던전 생성, 지향성 독가스 & 호드 광폭화 시뮬레이션, 보스 카운터 기믹, 최대 4인 실시간 코옵 동기화**를 결합하여 제작된 탑다운 전술 생존 슈팅 게임입니다.

기존의 단일 모놀리식 구조를 **100% 무손실 렉시컬 스코프 아키텍처**로 분리하여, 유지보수가 쉬운 모듈형 **`backend/` (Node.js HTTP + WebSocket)** 및 **`frontend/` (Three.js 3D 클라이언트)** 구조로 완성되었습니다.

## ⚡ 3초 만에 시작하기 (Quick Start)

별도의 복잡한 세팅 없이 바로 플레이할 수 있습니다.

### 방법 1. 윈도우 원클릭 실행 (가장 추천 ⭐)
프로젝트 폴더 내 **[`start.bat`](file:///start.bat)** 파일을 더블 클릭하세요.
* Node.js 설치 여부를 자동 확인하고 서버를 기동합니다.
* 약 1.5초 후 기본 웹 브라우저(`http://localhost:3000`)가 자동으로 열립니다.

---

### 방법 2. 콘솔 명령어 실행 (무설치 제로 디펜던시 지원)
본 프로젝트는 `npm install` 없이도 Node.js만 있으면 즉시 작동하도록 **Node.js 내장 RFC-6455 WebSocket 엔진**을 탑재하고 있습니다.

```bash
# 1. 패키지 설치 없이 즉시 실행
node backend/server.js

# 2. 브라우저에서 아래 주소로 접속
http://localhost:3000
```

> **선택사항 (npm 패키지 활용)**:
> ```bash
> npm install   # ws, express, cors 패키지 설치 (선택)
> npm start     # 서버 기동
> ```

## 🖧 멀티플레이 접속 가이드 (하마치 & LAN)

본 서버는 하나의 포트(`3000`)로 **정적 웹 서빙(HTTP)**과 **실시간 멀티플레이 통신(WebSocket)**을 동시에 처리합니다.

```
[방장 PC (Host)] ── 포트 3000 (HTTP / WS 통합 서빙) ──┬── [친구 1 (P2)]
                                                      ├── [친구 2 (P3)]
                                                      └── [친구 3 (P4)]
```

### 1. 방장 (Host, P1)
1. 하마치(Hamachi) 네트워크를 켜거나 같은 공유기(LAN)에 연결합니다.
2. `start.bat` (또는 Linux/macOS 환경: `./start.sh`)을 실행합니다.
3. 콘솔 창에 출력되는 **하마치 IPv4 주소**(`25.x.x.x`) 또는 **LAN 주소**를 확인합니다.
4. 브라우저(`http://localhost:3000`)에서 대기실 **[접속]** 버튼을 누릅니다.

### 2. 참가자 (Client, P2 ~ P4)
1. 방장의 하마치 네트워크에 접속합니다.
2. 웹 브라우저 주소창에 방장 주소를 입력합니다:
   ```text
   http://[방장의_하마치IP]:3000
   ```
3. 대기실 화면의 WebSocket 서버 주소창에 자동으로 `ws://[방장IP]:3000`이 채워집니다.
4. **[접속]** 버튼을 누르면 즉시 동기화되어 함께 플레이할 수 있습니다. (빈 슬롯은 스마트 AI 봇이 함께 출격합니다.)

## 🎮 조작법 & 전술 매뉴얼

마우스 360° 조준·사격과 직관적인 왼손 전술 단축키(`Q`, `E`, `F`, `Shift`, `Space`, `V`)로 일원화되어 있습니다.

| 키 / 버튼 | 동작 | 상세 설명 |
| :--- | :--- | :--- |
| **`W, A, S, D`** | 캐릭터 이동 | 8방향 전술 기동 |
| **`마우스 커서`** | 360° 조준 및 시선 | 마우스 커서 위치로 정밀 조준 (방향키 `↑, ↓, ←, →` 조준/사격 병행 지원) |
| **`마우스 좌클릭`** | 무기 사격 / 설치 | 주무기 발사 또는 바리케이드(`7`)/폭약통(`8`) 설치 |
| **`마우스 휠`** / **`1` ~ `8`** | 무기 퀵스왑 | 피스톨, 샷건, UZI, 라이플, 유탄발사기, 레일건, 바리케이드, 폭약통 |
| **`Q`** | **구급키트 / 나노 주사기** | 자가 응급처치 (기본 2.5초 채널링 +60 HP & 출혈 해제 / **나노 주사기 개조 시 0.6초 무감속 +80 HP**) |
| **`E`** | **아드레날린 스팀팩** | 즉시 투여하여 **6초간 이동속도 +35%, 연사속도 +25%**, 독가스 및 피격 경직 무시, 스태미나 40% 즉시 회복 |
| **`F` (홀드)** | **전술 상호작용** | 미션 노드 해킹/운반, 기절 아군 소생, 부상 아군 치료(기본 1.8초 / **주사기 개조 시 0.4초**), 제독소 가동 |
| **`Shift` (홀드)** | **전술 질주 (Sprint)** | 이동 중 홀드 시 스태미나(ST)를 소모하여 **이동속도 +42% 폭발적 가속** (비질주 시 스태미나 자동 회복) |
| **`Space`** / **`우클릭`** | **전술 대시 · 점프 회피** | 0.34초간 체공 무적 판정으로 돌진하며 낮은 장애물 월담 및 **보스/중간보스 바닥 충격파·회전 레이저 점프 회피** |
| **`V`** | **360° 전방위 기절 · 패링** | 주변 좀비를 밀쳐내고 1.6초 기절 + **보스/중간보스 돌진·정신집중 패턴 카운터 패링(4.2초 그로기 유발)** |
| **`B`** / **`T`** / **`U`** | **무기고 (Armory)** | 중앙/팝업 무기고 반경 내에서 무기 랜덤 강화, 슈트 강화, 무기 해금, 코어 장착/추출 |
| **`O`** / **`ESC`** | 설정 / 모달 닫기 | 사운드 볼륨, 그래픽 품질, 조작 가이드 확인 및 열려 있는 창 닫기 |

## ✨ 핵심 게임 시스템

* **확정 좀비 웨이브 정원 (`Wave Quota`) & 호드 소탕 시스템**:
  * 각 섹터 및 웨이브 단계마다 불분명한 무한 스폰 대신, **섹터 난이도·웨이브 회차·스쿼드 인원수에 맞춰 정밀 역산된 고정 좀비 출현 정원(`waveZombieQuota`)**이 배정됩니다. (1섹터 솔로 28마리부터 섹터당 +14마리, 웨이브 회차당 +8마리, 4인 풀스쿼드 스케일링 적용).
  * 정원수의 좀비가 전원 스폰될 때까지 침입구로부터 팩 단위로 쏟아져 나오며, 정원이 모두 출현한 후 **남은 잔당을 5마리 이하로 격멸해야만 웨이브 방어 성공 판정 및 다음 미션 단계/소강기(CALM) 무기고가 해금**됩니다.
  * HUD 중앙 및 상단에 `🌊 [웨이브 호드] 출현: N/M마리 | 생존: K마리 (5마리 이하 처치 시 완료)`가 실시간 표시되어 진행도를 직관적으로 파악할 수 있습니다.
* **❄️ 극저온 빙결 배럴 (`Cryo-Barrel`) 메커니즘 전면 혁신**:
  * **초고화력 극저온 폭발**: 기본 680 폭발 대미지 + 섹터별 스케일링(`+35%/섹터`) + 무기 강화 배율이 적용되어 대규모 호드를 단번에 궤멸시킵니다.
  * **100% 완전 동결 (Freeze) & 3D 얼음 결정 케이스**: 폭발 반경(기본 7.6m ~ 특수개조 10.5m) 내 모든 감염체를 **5.0초 ~ 7.5초간 완벽히 결빙(이동 및 공격 불가)**시키며, 반투명 극저온 얼음 큐브(`iceBlock`)가 감염체를 감싸는 시각 효과가 즉각 연출됩니다.
  * **쇄빙(Shatter) 추가 피해 (+35%)**: 동결된 감염체는 피격 시 **+35% 쇄빙 보너스 대미지**를 받으며, 사망 시 산산조각 나는 얼음 파편 이펙트가 발생합니다.
  * **지속성 영구동토 빙결 장판**: 모든 배럴 폭발 지점에 **5.5초~7.5초간 영구동토 장판**이 생성되어 진입하는 좀비를 75% 감속시키고 결빙을 유지시킵니다.
  * **총격 & 폭발 연쇄 반응 (Chain Reaction)**: 총알 피격뿐만 아니라 유탄, 수류탄, 바주카, 인접 배럴 폭발에 즉각 반응하여 방열된 배럴들이 연쇄적으로 대폭발을 일으킵니다.
* **절차적 비정형 맵 & 전장의 안개**: L자형, 팔각형, 십자형, 터널형 등 매 섹터마다 새로운 구조의 전장이 생성되며, 손전등 시야각 밖은 어둠 속에 잠깁니다.
* **지향성 독가스 (`Gas Wave`) & 호드 광폭화 (`Horde Berserk`)**:
  * 섹터 제한시간이 만료(`00:00`)되면 한쪽 방위로부터 치명적인 신경 독가스가 살포됩니다.
  * 동시에 **전장에 살아남은 모든 기존 좀비와 신규 스폰 좀비가 즉각 광폭화(`🔥광폭화`)**하여 **이동속도 +35%, 공격력 +35%**가 폭증하고 안광과 피부가 붉게 타오르며, 잠복 중이던 모든 벽면 침입구가 강제 개방됩니다.
* **보스 & 중간보스 `[Space]` 점프 회피 · `[V]` 기절 패링 기믹**:
  * **저거너트 (Sector 3)**: 돌진(`CHARGE`) 쇄도 중 타이밍 맞춰 **`[V]` 전방위 기절** 적중 시 돌진을 즉시 캔슬시키고 **4.2초간 그로기(받는 피해 1.75배)** 상태에 빠뜨립니다. 대지 강타 충격파 링은 **`[Space]` 점프**로 뛰어넘으면 피해를 무효화하고 스태미나 `+25`를 페이백받습니다.
  * **네크로 서모너 (Sector 6) & 애시드 퀸 (Sector 9)**: 광역 파동 시전 전 **1.35초간 붉은 정신집중 경고 링**이 차오릅니다. 이 순간 접근하여 **`[V]` 전방위 기절**을 적중시키면 패턴을 캔슬시키고 **4.2초 그로기(피해 1.75배)**를 유발하며, 파동이 퍼져나갈 때는 **`[Space]` 점프**로 회피할 수 있습니다.
  * **더 코어 (Sector 10 최종보스)**:
    * **`SHOCKWAVE` (에너지 충격파) & `LASERS_50` (4방향 회전 레이저)**: **`[Space]` 점프 체공**으로 충격파와 레이저 빔을 무피해로 뛰어넘을 수 있습니다 (`+30 ST` 보너스).
    * **`GRAPPLE` (촉수 포박)**: 코어의 촉수에 붙잡혔을 때 본인 또는 아군이 **`[V]` 전방위 기절**을 시전하면 촉수를 즉시 절단하고 3초간 속박 면역이 됩니다.
    * **`HOST` (황금 영양 숙주 흡수)**: 코어를 향해 전진하는 황금 숙주를 **`[V]` 전방위 기절**로 타격하면 코어 반대 방향으로 크게 튕겨내며 **3.5초 특대 기절**을 걸어 코어의 체력 회복을 저지합니다.
* **결정론적 난수 탄도 동기화**: 고유 `shotSeed`를 브로드캐스트하여 샷건 산탄부터 레일건 궤적까지 4인 화면에서 오차 없이 일치합니다.
* **직관적인 무기고 버튼 상태 피드백**: 무기고(`B`) 모달 내 모든 강화/해금/보급/코어 버튼은 현재 실행 가능 여부(무기고 거리, 보유 BP/부품/코어, 해금 섹터, 최대 레벨)에 따라 **활성 컬러 버튼**과 **비활성 회색(`disabled`) 버튼**으로 실시간 전환됩니다.

## 🔧 무기 해금(부품) & 전술 슈트 7종 업그레이드

### ① `⚙️ 무기 부품 (Weapon Parts)` 4대 수급처 및 무기 해금표
무기는 **요구 섹터 도달 + `⚙️ 부품` + `BP`**를 지불하여 해금합니다.

1. **전술 보급상자 (`📦보급상자`, 매 섹터 2개 투하)**:
   * **1번 보급상자 (청색 조명)**: 개봉 시 **`⚙️ 무기 부품 +1개` 100% 확정** + 주무기 탄약 보급
   * **2번 보급상자 (황색 조명)**: 개봉 시 **`⚙️ 무기 부품 +1개` 50% 확률** + 대량 탄약 보급
2. **섹터 클리어 확정 보상**: 매 섹터 미션 완수 및 탈출 성공 시 전원 **`⚙️ 부품 +1개` 확정 지급**
3. **전투 마일스톤 & 엘리트 처치**:
   * 중간보스(S3/S6/S9) 처치 시 **`⚙️ 부품 2개` 확정 드랍**
   * **65 / 140 / 230 콤보** 달성 시 발밑에 `⚙️ 부품` 추가 드랍
   * **골리앗(`GOLIATH`) · 데빌(`DEVIL`)** 엘리트 좀비 처치 시 일반 좀비 대비 **3.5배 확률**로 부품 드랍
4. **무기고 BP 부품 합성 (`⚙️ 부품 합성`)**: 부품이 부족할 때 무기고 상단에서 BP를 지불하여 즉시 부품을 합성할 수 있습니다 (`기본 750 BP + 합성 횟수당 650 BP + 섹터×200 BP`).

## 🛠️ 기술 스택 & 무손실 아키텍처

* **Front-End**: HTML5, CSS3, TailwindCSS, Three.js (r128), Web Audio API (합성 효과음)
* **Back-End**: Node.js (v16+), HTTP Server, WebSocket (RFC-6455 Native Engine + ws Library 지원)
* **Zero-Loss Lexical Scope**: 원본 단일 HTML에 존재하던 전역 변수·함수·밸런스 상수 간의 렉시컬 스코프를 유지한 채 실행 순서별 8대 도메인 스크립트로 분할하여 100% 버그 없는 로직 무손실을 달성했습니다.
