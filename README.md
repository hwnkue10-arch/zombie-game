## 🌟 프로젝트 소개

**BOXHEAD: THE CORE v3.6**는 클래식 플래시 명작 '박스헤드'의 감성을 계승하고, **Three.js 3D 렌더링, 절차적 비정형 전장 생성, 7대 미션 체계, 지향성 독가스 & 호드 광폭화, 4대 작전 특성화 클래스, 다목적 전술 드론, 보스 카운터 패링 기믹, 최대 4인 실시간 코옵 동기화**를 결합하여 제작된 탑다운 전술 생존 슈팅 게임입니다.

기존 단일 모놀리식 구조를 **100% 무손실 렉시컬 스코프 아키텍처**로 분리하여, 유지보수가 쉬운 모듈형 **`backend/` (Node.js HTTP + WebSocket)** 및 **`frontend/` (Three.js 3D 모듈러 엔진)** 구조로 완성되었습니다.

## ⚡ 3초 만에 시작하기 (Quick Start)

별도의 복잡한 설치 과정 없이 클릭 한 번으로 플레이할 수 있습니다.

### 방법 1. 윈도우 원클릭 실행 (가장 추천 ⭐)
프로젝트 폴더 내 **[`start.bat`](file:///start.bat)** 파일을 더블 클릭하세요.
* Node.js 설치 여부를 자동 확인하고 서버를 즉시 기동합니다.
* 약 1.5초 후 기본 웹 브라우저(`http://localhost:3000`)가 자동으로 열립니다.

---

### 방법 2. 콘솔 명령어 실행 (무설치 제로 디펜던시 지원)
본 프로젝트는 `npm install` 없이도 Node.js만 있으면 즉시 작동하도록 **Node.js 내장 RFC-6455 WebSocket 엔진**을 탑재하고 있습니다.

```bash
# 1. 패키지 설치 없이 즉시 실행
node backend/server.js

# 2. 웹 브라우저에서 아래 주소로 접속
http://localhost:3000
```

> **선택사항 (npm 패키지 활용)**:
> ```bash
> npm install   # ws, express, cors 패키지 설치 (선택)
> npm start     # 서버 기동
> ```

## 🖧 멀티플레이 접속 & 방화벽 가이드 (하마치 & LAN)

본 서버는 단일 포트(`3000`)로 **정적 웹 서빙(HTTP)**과 **실시간 멀티플레이 통신(WebSocket)**을 동시에 처리합니다.

```text
[방장 PC (Host)] ── 포트 3000 (HTTP / WS 통합 서빙) ──┬── [친구 1 (P2)]
                                                      ├── [친구 2 (P3)]
                                                      └── [친구 3 (P4)]
```

### 1. 방장 (Host, P1)
1. 하마치(Hamachi) 네트워크를 켜거나 같은 공유기(LAN)에 연결합니다.
2. **윈도우 방화벽 원클릭 등록 (최초 1회 권장)**:
   * **[`fix_firewall_for_hamachi.bat`](file:///fix_firewall_for_hamachi.bat)**을 우클릭하여 **[관리자 권한으로 실행]**합니다.
   * 3000번 포트 인바운드 허용 규칙이 자동 추가되고 하마치 네트워크 어댑터가 [개인 네트워크]로 안전하게 설정됩니다.
   * *(게임 종료 후 방화벽 규칙을 원상복구(삭제)하려면 **[`remove_firewall_rule.bat`](file:///remove_firewall_rule.bat)**을 실행하세요.)*
3. **[`start.bat`](file:///start.bat)**을 실행합니다. 콘솔 창에 출력되는 **하마치 IPv4 주소**(`http://25.xx.xx.xx:3000`)를 친구들에게 공유합니다.
4. 방장 본인은 브라우저(`http://localhost:3000`)에서 대기실 **[접속]** 버튼을 누릅니다.

### 2. 참가자 (Client, P2 ~ P4)
1. 방장의 하마치 가상 네트워크 방에 참가합니다.
2. 웹 브라우저 주소창에 방장이 알려준 하마치 웹 주소를 입력합니다:
   ```text
   http://[방장의_하마치IP]:3000
   ```
3. 대기실 화면의 WebSocket 서버 주소창에 자동으로 `ws://[방장IP]:3000`이 채워집니다.
4. **[접속]** 버튼을 누르면 즉시 동기화되어 스쿼드로 함께 출격할 수 있습니다!

## 🎖️ 4대 작전 특성화 클래스 (Specializations)

**Sector 2**를 클리어하면 스쿼드의 전술 역할을 극대화할 수 있는 **4대 특성화 클래스 선택 모달**이 열립니다. 각 대원은 고유한 영구 패시브와 강력한 **`[C]` 액티브 스킬**을 획득합니다.

```text
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│  🛡️ 선봉장      │  💥 돌격수      │  💉 의무관      │  🥷 척후병      │
│  (Juggernaut)   │  (Striker)      │  (Field Medic)  │  (Phantom Scout)│
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

### 1. 🛡️ 선봉장 (Juggernaut) — [탱커 & 진형 돌파]
* **영구 패시브**:
  * 받는 모든 피해 상시 `-15%` 경감
  * 일반 감염체를 밀치며 통과 (포위 고립 저지)
  * 10초마다 `+35 HP` 결사 재생 방어막 자동 충전
  * 최대 체력 `+35 HP` 증가
* **`[C]` 액티브: 『전술 도발 & 결사 요새』** (쿨타임 40초 / 지속 6초):
  * **18m 반경** 내 모든 일반 감염체의 어그로를 본인에게 강제 집중
  * `+80` 임시 쉴드 즉시 획득 & 발동 중 받는 피해 추가 `-40%` 경감 (총 `-50%` 감쇄)

### 2. 💥 돌격수 (Striker) — [초고화력 & 탄환 관통]
* **영구 패시브**:
  * 전 무기 기본 관통력 `+1` (모든 탄환이 1체 추가 관통)
  * 필드 탄약팩 습득량 `+35%` 보너스
* **`[C]` 액티브: 『전술 과충전 (Overcharge)』** (쿨타임 30초 / 지속 6초):
  * 총기 공격력 `+25%` & 연사속도 `+35%` (발사 딜레이 26% 감소)
  * 탄속 `+30%`, 타격 스턴 `+35%` 및 **추가 관통력 +1 (총 +2 관통 극딜 모드)**

### 3. 💉 의무관 (Field Medic) — [스쿼드 생존 & 광역 치유]
* **영구 패시브**:
  * 기절한 아군 수동 구출 소생 시간 `3.5초` (기본 8.0초 대비 56% 단축)
  * 본인이 회복제나 스팀팩 사용 시 **반경 4m 내 아군에게 25% 효과 동시 공유**
* **`[C]` 액티브: 『나노 치유 필드』** (쿨타임 40초 / 지속 7초):
  * 발동 위치 바닥 반경 5m에 **3D 에메랄드 치유 장판 및 회전 링** 전개
  * 장판 안의 모든 아군 **초당 +6 HP 지속 재생** 및 **출혈·산성·감전·중독 상태이상 즉시 완전 정화**

### 4. 🥷 척후병 (Phantom Scout) — [초기동 & 은신 암살]
* **영구 패시브**:
  * 기본 이동속도 `+15%` 영구 증가
  * `[Space]` 회피 점프 도약 비거리 `+25%` 증가
  * 스태미나 회복속도 `+50%` 증가 / 점프 소모량 `-35%` 절감
* **`[C]` 액티브: 『연막 완전 은신 & 암살 관통샷』** (쿨타임 35초 / 지속 7.5초):
  * 발동 즉시 연막 폭발을 일으키며 **7.5초간 어그로 100% 해제 완전 은신** (은신 중 이속 `+20%`)
  * 은신 해제 후 발사하는 첫 번째 탄환은 **2배 피해(보스 제외) 및 무한 관통 탄환**으로 적중

## 🛸 다목적 전술 드론 시스템 (Tactical Drone System)

플레이어의 어깨 위를 호버링하며 전술을 보조하는 인공지능 지원 드론 시스템입니다. 무기고(`U`)의 드론 모듈 베이에서 단계별로 업그레이드할 수 있습니다.

1. **🧲 자력 수거 모듈 (Magnetic Collector Module, Lv.1~3)**:
   * 주변에 드랍된 탄약팩, 생체 BP 박스, 구급키트, 무기 부품, 🧬변이 코어를 **최대 10m 반경에서 자력으로 플레이어에게 자동 견인 흡수** (Lv.1 5m / Lv.2 7.5m / Lv.3 10m).
2. **🛡️ 탄약 요격 방어 모듈 (Point Defense Interceptor Module, Lv.1~3)**:
   * 플레이어를 향해 날아오는 스핏터의 산성 침, 네크로 서모너의 암흑 구체 등 적 원거리 투사체를 감지하여 레이저로 요격 격추 (재사용 쿨타임 Lv.1 2.0초 → Lv.2 1.2초 → Lv.3 **최저 0.6초**).
3. **💉 의무 나노 원격 소생 모듈 (Medical Nanite Reviver Module, Lv.1 특수)**:

## 🛠️ 기술 스택 & 무손실 아키텍처

* **Front-End**: HTML5, CSS3, TailwindCSS, Three.js (r128), Web Audio API (내장 합성 효과음)
* **Back-End**: Node.js (v16+), HTTP Server, WebSocket (RFC-6455 내장 제로 디펜던시 엔진 + ws 라이브러리 하이브리드 지원)
* **Zero-Loss Lexical Architecture**: 원본의 모든 전역 상태와 함수 렉시컬 스코프를 100% 무손실 유지한 상태로 거대 함수를 단일 책임 단위로 분해(Phase 1)하고 18개 세부 도메인 스크립트로 모듈화(Phase 2)하여 AI/개발자 탐색 속도와 유지보수성을 극대화했습니다.
